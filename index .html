Bienvenue dans les applications du manuel

Chaque chapitre du manuel possède son application interactive : elle vous permet de passer les tests validés en ligne, d'obtenir vos résultats calculés et représentés graphiquement, puis de les exporter pour votre portfolio de compétences.

Ces applications ne remplacent pas le travail du manuel : elles le préparent et le prolongent. Ce qui est attendu de vous, c'est l'analyse de vos résultats, pas leur simple collecte.

Mode d'emploi : touchez la carte du chapitre qui vous intéresse. Chaque application s'ouvre sur un onglet « 🎯 Ma mission » qui précise ce qui est demandé. Vos réponses restent sur votre appareil — rien n'est envoyé. Pensez à copier ou imprimer votre synthèse avant de fermer la page.
