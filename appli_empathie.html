L'empathie selon Baron-Cohen

Simon Baron-Cohen (2003) propose que le cerveau humain se situe sur un spectre entre deux dimensions : l'empathie (capacité à capter et répondre aux émotions d'autrui) et la systématisation (tendance à analyser et construire des systèmes). Les deux ne s'excluent pas — on peut être fort sur les deux (type B = Balanced).

Le QE et le QS mesurent ces deux dimensions. Leur croisement détermine votre type de cerveau : Type E (empathisant), Type S (systématisant), Type B (équilibré), Extrême-E ou Extrême-S.

QE : Baron-Cohen & Wheelwright (2004). Version française : C. Besche-Richard, M. Olivier et B. Albert.
QS : Baron-Cohen et al. (2003). Systemizing Quotient.
Application : Sameh Bekri & Besma Brahmi, 2026.

🧠 Type E — Empathisant

QE nettement > QS. Vous captez les émotions et les intentions. Force : écoute, intuition sociale. Piège : surinvestissement émotionnel.

⚙️ Type S — Systématisant

QS nettement > QE. Vous analysez, classez, construisez. Force : rigueur, logique. Piège : difficulté à lire les signaux émotionnels subtils.

⚖️ Type B — Équilibré

QE ≈ QS. Vous naviguez entre les deux registres. Force : polyvalence. Défi : approfondir chaque dimension.

📊 Moyennes de référence

QE : femmes ~47, hommes ~42. QS : femmes ~24, hommes ~30. Score max : 80 pour chaque test.
